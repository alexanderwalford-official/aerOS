# The packages on the package server (docs/PACKAGES.md): the ones that used to come built into
# AerOS, and newer ones like the desktop.
# One a line: name, version, description. Each one's program is next to this file (snake.aer),
# and the files it comes with, if any, are in the folder named after it (viewer/). Publish them
# all with:
#
#     python3 tools/aerpkg.py publish-all packages
#
# which sends only the ones that have changed. Give a package a new version here whenever it
# changes, so pkg update offers it.
anim 1.0 Spinners, progress bars and moving text: AerLang's text animations
bench 1.0 How fast AerOS reads and writes its disk
clip 1.0 A 6 second video, to try AerOS's video player on
desktop 1.1 A desktop with windows: clock, files, notes, calculator, your installed apps, power options and settings
guess 1.0 Guess the number from 1 to 100
maze3d 1.1 A maze in 3D, seen from inside: the classic maze or a new one up to 55 x 55, with crystals to find and ghosts that chase you
move 1.0 Move a square with the arrow keys: a small example of a game
snake 1.0 Snake, with high scores
viewer 1.0 A picture viewer (BMP), with two pictures to try it on
webserve 1.0 A small web server: shows a folder of files to web browsers
browser 1.1 A basic text based web browser
