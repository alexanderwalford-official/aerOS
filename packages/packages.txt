# The packages on the package server (docs/PACKAGES.md): the ones that used to come built into
# AerOS, and newer ones like the desktop.
# One a line: name, version, description. Each one's program is next to this file (snake.aer),
# and the files it comes with, if any, are in the folder named after it (viewer/). Publish them
# all with:
#
#     python3 tools/aerpkg.py publish-all packages
#
# which sends only the ones that have changed. Give a package a new version here whenever it
# changes, so pkg update offers it.
anim 1.0 Spinners, progress bars and moving text: AerLang's text animations
bench 1.0 How fast AerOS reads and writes its disk
clip 1.0 A 6 second video, to try AerOS's video player on
desktop 1.6 A desktop with windows: clock, files, notes, calculator, a web browser, your installed apps, power options, settings and a live system monitor
guess 1.0 Guess the number from 1 to 100
maze3d 1.3 A maze in 3D, seen from inside: a pitch black dungeon of stone walls, flagstones and cobbles, seen by flashlight, the classic maze or a new one up to 55 x 55, with crystals to find, ghosts that chase you, and music and sound effects
move 1.0 Move a square with the arrow keys: a small example of a game
snake 1.0 Snake, with high scores
viewer 1.0 A picture viewer (BMP), with two pictures to try it on
webserve 1.0 A small web server: shows a folder of files to web browsers
browser 1.3 A basic text based web browser, for http:// and https:// pages
browsgui 1.4 A graphical web browser: click links, scroll, pictures in the page. Needs the graphics screen (start from the CD)
knocks 1.0 Four Knocks: a horror game in a pitch black observatory, where something blind hunts you by the sounds you make. Use headphones
lantern 1.0 Lantern: a pixel art adventure in a new valley every game, made from a seed you can replay. Save your village from a villain by day and by lantern light; raids, rescues and choices change which of five endings you get
