AerOS packages

Extra apps for AerOS, installed with its pkg app.

Installing one

At the AerOS prompt, allow this site through the firewall, then use pkg:

fw web packages.intercon.network 80
pkg list
pkg install <name>

Every package is signed by its maker. AerOS checks the signature with a key built into it before installing anything, shows you what the program could do, and asks first. A package changed by a single byte is refused.
